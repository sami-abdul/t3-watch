THE THINGS BETWEEN YOUR TOOLS

One place to see what needs you.

01 / GitHub Actions
Failed CI, jobs GitHub never started, and scheduled workflows that stopped running while the last result stayed green.
02 / API keys
Read-only calls check that keys still work. Stripe, OpenAI, Anthropic, Sentry, Airtable, Asana, Calendly, Jotform, Missive, Pipedrive and Vimeo.
03 / Sites and APIs
HTTP responses and expected content. A dropped request gets checked again before it wakes you.
04 / AWS metrics
CloudWatch metrics through your AWS CLI login. Pick the metric and threshold that matter to your service.
05 / Scheduled jobs
A job pings Watch when it finishes. If it misses its deadline or reports a failure, Watch notices.

ON YOUR MACHINE

You choose what Watch may read.

Pick folders and logins before the first scan. Watch suggests checks from your projects, runs each once, then waits for you to turn them on.

Paste keys on the page. Vendor keys stay encrypted on your machine, and agents never receive their values. Vendor calls only read.

WHEN SOMETHING CHANGES

Your agent has the context.

Signed alerts wake your Watch thread in T3 Code. The agent investigates and leaves a note beside the check.

The local page and MCP server also work with Claude Code and Codex. T3 Code is required for alerts that wake a thread.

Watch holds failures when its own internet connection is down or slow. A passing check needs two bad runs to fail; recovery counts at once.

UP AND WATCHING

Start with a demo.
Keep it running.

You need Node 24 or newer, macOS or Linux, and a machine that stays on. Watch runs in the background at login.

The page stays on your machine or your own Tailscale network. There is no hosted Watch.

Read the install guide ↗
Try it with sample data
npx @lfg-labs/t3-watch demo

Nothing scans your projects or contacts your accounts. Ctrl-C stops it and removes the sample data.

Install your own Watch
npm install -g @lfg-labs/t3-watch
t3-watch install

Open the sign-in link it prints. Choose what it may read, scan, then turn on the checks you want.

BUILT IN THE OPEN

Free. Open source. Yours to run.

The checks cost no model tokens. Your agent uses your own account when it investigates. Add a vendor with a JSON description, or ask your agent to draft a new check.
